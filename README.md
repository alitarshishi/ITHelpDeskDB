# ITHelpDeskDb

This repository contains the ITHelpDeskDb Razor Pages project (targeting .NET 10).

Changes in this commit:
- Added migration: 20260716054043_addTokenValidFrom
- Updated README with basic project description

To run locally:
1. Ensure .NET 10 SDK is installed.
2. Update the connection string in appsettings.json.
3. Run `dotnet ef database update` to apply migrations.
